# Logistic Regression — Python Code Example

This tutorial uses **Python**, **NumPy**, **scikit-learn**, and **Matplotlib** to predict whether a student will pass an exam based on hours studied.

## 1. Training Data

| Hours Studied (x) | Passed Exam (y) |
|---:|---:|
| 1 | 0 |
| 2 | 0 |
| 3 | 0 |
| 4 | 1 |
| 5 | 1 |
| 6 | 1 |

- `0` = Fail
- `1` = Pass

## 3. Complete Python Code

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LogisticRegression

# Step 1: Create training data
X = np.array([[1], [2], [3], [4], [5], [6]])
y = np.array([0, 0, 0, 1, 1, 1])

# Step 2: Create and train the Logistic Regression model
model = LogisticRegression()
model.fit(X, y)

# Step 3: Display learned coefficients
intercept = model.intercept_[0]
weight = model.coef_[0][0]
print("Intercept (w0):", intercept)
print("Weight (w1):", weight)

# Step 4: Predict for a student who studied 4.5 hours
hours = np.array([[4.5]])
prediction = model.predict(hours)[0]
probability = model.predict_proba(hours)[0][1]

print("\nHours Studied:", hours[0][0])
print("Probability of Passing:", round(probability, 4))
print("Predicted Class:", prediction)
print("Prediction:", "PASS" if prediction == 1 else "FAIL")

# Step 5: Show predictions for different study hours
print("\nHours | Probability | Prediction")
print("--------------------------------")
for hour in range(1, 11):
    sample = np.array([[hour]])
    prob = model.predict_proba(sample)[0][1]
    pred = model.predict(sample)[0]
    print(f"{hour:5d} | {prob:.4f}      | {pred}")

# Step 6: Plot the predicted probability curve
X_plot = np.linspace(0, 10, 200).reshape(-1, 1)
probabilities = model.predict_proba(X_plot)[:, 1]

plt.figure(figsize=(9, 5))
plt.scatter(X, y, label="Training Data", s=80)
plt.plot(X_plot, probabilities, label="Logistic Regression")
plt.axhline(y=0.5, linestyle="--", label="Decision Threshold = 0.5")
plt.xlabel("Hours Studied")
plt.ylabel("Probability of Passing")
plt.title("Logistic Regression — Student Exam Prediction")
plt.legend()
plt.grid(True)
plt.show()
```

## 4. Understanding the Mathematics

The fitted model learns an intercept $w_0$ and weight $w_1$. It calculates the linear score:

$$
z = w_0 + w_1x
$$

Then it converts the score into a probability using the **sigmoid function**:

$$
P(y=1\mid x) = \sigma(z) = \frac{1}{1+e^{-z}}
$$

For a student who studied 4.5 hours, calculate the probability manually:

```python
w0 = model.intercept_[0]
w1 = model.coef_[0][0]
x = 4.5

z = w0 + w1 * x
probability = 1 / (1 + np.exp(-z))

print("Linear Score:", z)
print("Probability:", probability)
print("Probability (%):", probability * 100)
```

Compare the manual result to scikit-learn:

```python
print(model.predict_proba([[4.5]])[0][1])
```

Both methods calculate the same class-1 probability (within normal floating-point precision).

## 5. Classification Threshold

By default, a binary Logistic Regression model predicts class `1` when its estimated probability is at least `0.5` and class `0` otherwise.

$$
\hat{y} =
\begin{cases}
1 & \text{if } P(y=1\mid x) \ge 0.5 \\
0 & \text{otherwise}
\end{cases}
$$

The graph generated by the complete program displays training observations, the fitted sigmoid probability curve, and a horizontal line at the 0.5 threshold.

## 6. Code Summary

| Python Code | Purpose |
|---|---|
| `LogisticRegression()` | Create the classifier |
| `model.fit(X, y)` | Learn coefficients from training data |
| `model.coef_` | Read learned weights |
| `model.intercept_` | Read learned intercept |
| `model.predict(X)` | Predict class 0 or 1 |
| `model.predict_proba(X)` | Calculate probabilities for each class |
| `np.exp(-z)` | Calculate the exponential term in sigmoid |
| `plt.plot()` | Plot the fitted probability curve |

> **Note:** scikit-learn's `LogisticRegression()` uses regularization by default, so its learned coefficients are not necessarily the same as those in a hand-chosen illustrative sigmoid equation.

**Key takeaway:** `fit()` learns the parameters, `predict_proba()` returns class probabilities, and `predict()` converts probabilities into class predictions.
